# Team OKR Tracker

No backend. Everything is saved in the browser.

- Run locally: `npm install` then `npm run dev`, and open the address it prints (usually http://localhost:5173).
- Or just double-click `index.html` (also available as `../OKR Tracker.html`).
- Deploy: `npm run build` and upload the `dist` folder to any static host.

The earlier Supabase version is kept in `_supabase-version/` and is not used.
